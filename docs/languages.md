# Описание C++

Единственное встроенное описание — `blockwright/languages/cpp.toml`. Оно содержит общие конструкции C/C++ и правила потоков C++; наследование от отдельного C-описания устранено, грамматика C не требуется.

`functions` описывает определения и имена функций, `statements` — узлы условий/циклов/переходов, `io` — стандартные потоки и вызовы, `strings` — строковые литералы. Загрузка и проверки TOML находятся в `blockwright/langs.py`.

Учебные преобразования вынесены в `blockwright/study.py`; они используют AST и консервативные шаблоны. Конфигурация не должна превращать неизвестное выражение в пропуск. Направления I/O представлены отдельными INPUT/OUTPUT, обычный возврат — Return(value, main).

Реестр сохраняет механизм расширения/обработчиков для локальной настройки C++, но другие языки не входят в продукт, пакет зависимостей и поставляемые грамматики.
