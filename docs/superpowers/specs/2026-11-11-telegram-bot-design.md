# Telegram-бот Blockwright

Утверждено пользователем: публичный бот на Go, сборка Docker сейчас,
развёртывание позже после предоставления SSH и токена.

Бот принимает `/start` и документы C++, запускает существующий Python CLI
и отправляет PNG документами. Токен поступает через `TELEGRAM_BOT_TOKEN`.
Long polling не требует входящего порта и публичного домена.

Параметры генерации: `--no-ui --for-style hexagon --detail study --checks hide
--io-style symbols --page-height 0 --png 2`; дополнительно `--no-html`.
Несколько функций дают несколько PNG.

Выбран отдельный Go-бот поверх готового генератора: это сохраняет поведение
CLI. Переписывание генератора на Go слишком объёмно; Python-бот расходится
с выбранным пользователем языком.

Ограничения: вход 256 КиБ, две параллельные задачи, одна задача на пользователя,
таймаут 90 секунд, максимум 10 PNG общим размером 20 МиБ. Временные файлы
удаляются после обработки. C++ не компилируется и не исполняется.
Контейнер без root, с read-only корнем, ограничениями CPU, памяти и процессов.
Токен не включается в образ и логи.

Сейчас проверяются mock Telegram API и реальный генератор в контейнере.
Проверка настоящего бота требует токена и проводится при развёртывании.
