# План реализации Telegram-бота

Цель: публичный Go-бот с готовым Docker-образом.
Спецификация: `docs/superpowers/specs/2026-11-11-telegram-bot-design.md`.

1. Создать `telegram-bot/`: стандартная библиотека Go, Telegram HTTP API,
   ограниченное скачивание, обработка CLI, отправка документов, остановка.
   Проверка: тесты httptest, `go test -race ./...`, `go vet ./...`.
2. Создать Dockerfile, `.dockerignore`, `compose.yaml`, инструкцию запуска.
   Go собирается отдельной стадией, Python устанавливается в venv,
   PNG формирует librsvg с Liberation Serif. Проверка: сборка и Compose config.
3. Проверить `/start`, ошибки и лимиты через mock API; реальный PNG ×2
   получить внутри контейнера с параметрами пользователя. Проверить UID,
   отсутствие токена, выход без настройки и отсутствие оставшихся контейнеров.

Ответственность: сабагент изменяет только `telegram-bot/`, основной агент —
Docker и документацию, затем проверяет интеграцию. Существующий код не меняется.
Push и развёртывание в этот этап не входят.
